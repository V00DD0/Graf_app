# Карта связей 2.5.0

Автономный редактор карт знакомств и родственных связей. Откройте [HTML](Karta-2.1.html) в современном браузере или скачайте установщик из раздела **Artifacts** успешного запуска [GitHub Actions](https://github.com/V00DD0/Graf_app/actions).

- **Windows** — запустите установщик `Karta-2.5.0-Windows.exe` и откройте «Карта связей» через меню «Пуск». В переносном ZIP рядом будут `Karta.exe` и `Karta-2.1.html`. Чтобы пользоваться прежней картой напрямую, сохраните прежний путь к HTML, браузер и его профиль. Для переноса в другое место экспортируйте копию из старой версии.
- **Linux** — установите DEB или RPM и откройте «Карта связей» из меню приложений. На x86-64 также доступен AppImage. Сделайте его исполняемым и запустите. Если в системе нет FUSE, используйте `--appimage-extract-and-run`. Все пакеты используют один путь к HTML в пользовательском каталоге данных и открывают его в браузере по умолчанию через `xdg-open`.
- **Android** — для обновления опубликованных APK 2.2 и 2.4 нужен APK с идентификатором `local.karta.app` и исходной подписью. Пакеты 2.3 (`local.karta.preview23`) и 2.5.0 Preview (`local.karta.preview24`) устанавливаются отдельно от опубликованных APK. Для переноса в другой канал экспортируйте резервную копию каждой карты и импортируйте её в соответствующую вкладку. Для шифрованных карт храните пароль от копии.

**＋ Карта** создаёт независимую вкладку. Крестик закрывает вкладку. Её можно вернуть через «Открыть закрытую карту». При перезагрузке открывается последняя активная карта этого окна. У каждой карты свои люди, связи, кольца, фильтры, сохранённые виды и масштаб. Основная вкладка открывает карту предыдущей версии. Команды импорта, экспорта и шифрования относятся к активной карте. Имена вкладок видны до ввода пароля. Отмена и повтор сохраняются при переключении в текущем сеансе для обычных карт. При выходе из зашифрованной карты её история очищается.

**Оформление → Сохранённые виды** позволяет сохранить несколько расположений одних и тех же людей. **Найти человека** открывает поиск по имени или номеру. Enter открывает первую карточку, Escape возвращает к поиску.

**Группировка → Итоги звонков** принимает CSV с заголовком `phone,count` или `phone,count,start,end`. Для всех строк используйте общий период в формате ГГГГ-ММ-ДД. Пример строки с периодом: `+12025550137,12,2026-09-01,2026-09-30`. Нулевой итог и отсутствие данных различаются. На Android в разделе файлов можно выбрать контакт из системной телефонной книги. По отдельному согласию приложение подсчитает входящие и исходящие разговоры длительностью больше нуля за 90 дней. Результат виден в предпросмотре до применения. Общие номера пропускаются. Для переносимости используйте международную форму с кодом страны.

Защита локальной карты и зашифрованной резервной копии использует AES-256-GCM. Новый пароль должен содержать не менее 8 символов, заглавную и строчную буквы (включая кириллицу), цифру и спецсимвол. При задании пароль вводится дважды. Флажок позволяет временно увидеть оба поля. Прежние пароли продолжают открывать сохранённые карты и копии. Обычный экспорт JSON остаётся открытым.

В меню **⋯ → Зашифрованная копия** сохраните активную карту. На Android приложение, используя системный выбор файла, перечитывает записанную копию и сверяет SHA‑256. Для восстановления выберите **⋯ → Импорт JSON** на любой платформе и введите пароль. После проверки AES-GCM и структуры данных приложение попросит подтвердить замену непустой карты. Локальное сохранение использует транзакции IndexedDB, поэтому редактор продолжает читать карты предыдущих версий в том же профиле браузера или Android-приложении.

Автогруппировка может учитывать текущие фильтры. Предпросмотр подбирает шаг обычных колец и показывает оставшиеся наложения. Индивидуальные радиусы и закреплённые позиции сохраняются. При расчёте родства достаточно указать общего родителя, чтобы распознать братьев и сестёр. В режиме просмотра карточка показывает предыдущие союзы с датой окончания.

В разделе **Оформление** можно выбрать готовую палитру, задать основной и акцентный цвета и отключить анимацию панелей. Палитра общая для всех карт в этом браузере или приложении. Цвет полотна, сетка, кольца и линии секторов настраиваются там же для активной карты.

## Разработка и проверка

Команда `python build.py` собирает автономный `Karta-2.1.html` из `src`. Имя сохранено для совместимости с Windows-запускателем. Тесты `test-*.py` используют Playwright и Chromium. Переменная `CHROMIUM` может указывать на установленный браузер. Для проверки через локальный HTTP-сервер задайте `KARTA_TEST_URL` с адресом страницы. `benchmark.py` измеряет импорт, открытие фильтров, перетаскивание, отмену и масштабирование двумя пальцами на синтетических графах с фото и вложениями.

Сборка Windows использует NSIS, Linux — `packaging/linux/build.sh`. Android требует JDK 17, SDK Platform 35 и Build Tools 35.0.0. Workflow `windows.yml` собирает пакеты трёх платформ и запускает тесты. На эмуляторе исходные версии 2.3, 2.4.2 и 2.5.0 устанавливаются последовательно с общей тестовой подписью. Сценарий проверяет сохранённый вид из 2.3 и открытие зашифрованной карты, созданной в 2.4.2.

Для релизного Android APK используйте workflow `release.yml`. Он запускается вручную после появления в основной ветке или при отправке тега `v*`. В окружении `android-release` задайте секрет `KARTA_KEY_BASE64` с исходным хранилищем ключа PKCS#12 или JKS и секрет `KARTA_KEY_PASSWORD` с его паролем. Если в хранилище несколько ключей, задайте переменную `KARTA_KEY_ALIAS`. Для отдельного пароля записи используйте секрет `KARTA_KEY_PASSWORD_OVERRIDE`. Сборка сверяет сертификат с APK 2.4 и выдаёт `Karta-2.5.0.apk` при совпадении. Храните хранилище и пароли вне Git.
