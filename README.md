# Карта связей 2.4

Автономный редактор карт знакомств и родственных связей. Откройте [HTML](Karta-2.1.html) в браузере или скачайте готовый пакет.

- [Windows ZIP](downloads/Karta-2.4-Windows.zip) — распакуйте оба файла в одну папку и запустите Karta.exe. Для доступа к прежним картам используйте прежний браузер, профиль и путь к HTML.
- [Android APK, тестовый канал](downloads/Karta-2.4-test.apk) — подписан тем же тестовым сертификатом, что и 2.2. Версия preview23 устанавливалась отдельно. Для переноса откройте её, экспортируйте JSON и импортируйте его в нужную карту 2.4.

**＋ Карта** создаёт независимую вкладку. Крестик закрывает вкладку. Её можно вернуть через «Открыть закрытую карту». При перезагрузке открывается последняя активная карта этого окна. У каждой карты свои люди, связи, кольца, фильтры, сохранённые виды и масштаб. Основная вкладка открывает карту предыдущей версии. Команды импорта, экспорта и шифрования относятся к активной карте. Имена вкладок видны до ввода пароля. Отмена и повтор сохраняются при переключении в текущем сеансе для обычных карт. При выходе из зашифрованной карты её история очищается.

**Оформление → Сохранённые виды** позволяет сохранить несколько расположений одних и тех же людей. **Найти человека** открывает поиск по имени или номеру. Enter открывает первую карточку, Escape возвращает к поиску.

**Группировка → Итоги звонков** принимает CSV с заголовком `phone,count` или `phone,count,start,end`. Для всех строк используйте общий период в формате ГГГГ-ММ-ДД. Пример строки с периодом: `+12025550137,12,2026-09-01,2026-09-30`. Нулевой итог и отсутствие данных различаются. На Android в разделе файлов можно выбрать контакт из системной телефонной книги. По отдельному согласию приложение подсчитает входящие и исходящие разговоры длительностью больше нуля за 90 дней. Результат виден в предпросмотре до применения. Общие номера пропускаются. Для переносимости используйте международную форму с кодом страны.

## Разработка и проверка

Файлы для редактирования находятся в src. Команда `python build.py` собирает автономный Karta-2.1.html. Имя сохранено для совместимости с Windows-запускателем. Установите Python, Playwright и Chromium. Переменная CHROMIUM может указывать на исполняемый файл браузера. Запустите test-browser.py, test-rings.py, test-views-calls.py и test-workspaces.py. benchmark.py измеряет импорт, открытие фильтров и перемещение с записью на синтетических графах.

Android требует JDK 17, Android SDK Platform 35 и Build Tools 35.0.0. Workflow windows.yml проверяет запуск EXE, редактор и Android на эмуляторе. Для отдельной подписанной сборки workflow release.yml использует окружение android-release, секреты KARTA_KEY_BASE64 и KARTA_KEY_PASSWORD и переменную KARTA_CERT_SHA256 (SHA-256 сертификата без двоеточий в нижнем регистре). Обновления Android требуют того же идентификатора пакета и сертификата подписи. Храните резервную копию ключа вне репозитория.
