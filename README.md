# Карта связей 2.5.3 Standalone

Отдельная установка автономного редактора с собственной базой карт. Для переноса данных сохраните резервную копию каждой карты в прежней версии и импортируйте её в нужную вкладку. Можно открыть [HTML](Karta-2.1.html) в современном браузере.

- **Windows** — запустите `Karta-Standalone-2.5.3-Windows.exe`. Приложение устанавливается для текущего пользователя в `%LOCALAPPDATA%\KartaStandalone`. Запускайте его из меню «Пуск» через «Карта связей Standalone». В переносном ZIP находятся `Karta.exe` и `Karta-2.1.html`.
- **Linux** — установите пакет `karta-svyazey-standalone` (DEB или RPM). Для x86‑64 можно использовать AppImage. При отсутствии FUSE запустите AppImage с `--appimage-extract-and-run`. Пакеты используют каталог `karta-standalone` в пользовательском каталоге данных и открывают редактор через `xdg-open`.
- **Android** — установите подписанный `Karta-Standalone-2.5.3.apk`. Идентификатор `local.karta.standalone` позволяет установить его рядом с `local.karta.app`.

**＋ Карта** создаёт независимую вкладку. Крестик закрывает вкладку. Её можно вернуть через «Открыть закрытую карту». При перезагрузке открывается последняя активная карта этого окна. У каждой карты свои люди, связи, кольца, фильтры, сохранённые темы и масштаб. Команды импорта, экспорта и шифрования относятся к активной карте. Имена вкладок видны до ввода пароля. Отмена и повтор сохраняются при переключении в текущем сеансе для обычных карт. При выходе из зашифрованной карты её история очищается.

**Оформление → Сохранённые темы** позволяет сохранить несколько расположений одних и тех же людей. Кнопка «Сохранить тему» запоминает расположение и настройки полотна. Кнопка «Открыть вид» восстанавливает выбранную тему. В разделе «Окружности» у каждого заданного радиуса есть настройки линии. **Найти человека** открывает поиск по имени или номеру. Enter открывает первую карточку, Escape возвращает к поиску.

**Группировка → Итоги звонков** принимает CSV с заголовком `phone,count` или `phone,count,start,end`. Для всех строк используйте общий период в формате ГГГГ-ММ-ДД. Пример строки с периодом: `+12025550137,12,2026-09-01,2026-09-30`. Нулевой итог и отсутствие данных различаются. На Android откройте **⋯ → Добавить из контактов**. Можно отметить несколько записей, искать по имени или номеру и выбрать всю телефонную книгу. Для этого Android запрашивает доступ к контактам. Для одного контакта доступен системный выбор. Повторяющиеся номера пропускаются, а для записи с несколькими номерами берётся основной номер. Кнопка **Добавить и учесть звонки** позволяет отметить несколько записей или выбрать всю телефонную книгу. Для карточек, которые уже есть на карте, используйте **Группировка → Обновить статистику звонков** и выберите нужные записи. По отдельному согласию приложение подсчитает входящие и исходящие разговоры длительностью больше нуля за 90 дней для выбранных номеров. Результат виден в предпросмотре до применения. Общие номера пропускаются. Для переносимости используйте международную форму с кодом страны.

Защита локальной карты и зашифрованной резервной копии использует AES-256-GCM. Новый пароль должен содержать не менее 8 символов, заглавную и строчную буквы (включая кириллицу), цифру и спецсимвол. При задании пароль вводится дважды. Флажок позволяет временно увидеть оба поля. Прежние пароли продолжают открывать сохранённые карты и копии. Обычный экспорт JSON остаётся открытым.

В меню **⋯ → Зашифрованная копия** сохраните активную карту. На Android приложение, используя системный выбор файла, перечитывает записанную копию и сверяет SHA‑256. Для восстановления выберите **⋯ → Импорт JSON** на любой платформе и введите пароль. После проверки AES-GCM и структуры данных приложение попросит подтвердить замену непустой карты. Локальное сохранение использует транзакции IndexedDB. Standalone открывает собственное хранилище и читает копии прежних версий через импорт.

Автогруппировка может учитывать текущие фильтры. Предпросмотр подбирает шаг обычных колец и показывает оставшиеся наложения. Индивидуальные радиусы и закреплённые позиции сохраняются. При расчёте родства достаточно указать общего родителя, чтобы распознать братьев и сестёр. В режиме просмотра карточка показывает предыдущие союзы с датой окончания.

В разделе **Оформление** можно выбрать готовую палитру, задать основной и акцентный цвета и отключить анимацию панелей. Палитра общая для всех карт в этом браузере или приложении. Цвет полотна, сетка, кольца и линии секторов настраиваются там же для активной карты.

## Разработка и проверка

Команда `python build.py` собирает автономный `Karta-2.1.html` из `src`. Имя сохранено для совместимости с Windows-запускателем. Тесты `test-*.py` используют Playwright и Chromium. Переменная `CHROMIUM` может указывать на установленный браузер. Для проверки через локальный HTTP-сервер задайте `KARTA_TEST_URL` с адресом страницы. `benchmark.py` измеряет импорт, открытие фильтров, перетаскивание, отмену и масштабирование двумя пальцами на синтетических графах с фото и вложениями.

Сборка Windows использует NSIS, Linux — `packaging/linux/build.sh`. Android требует JDK 17, SDK Platform 35 и Build Tools 35.0.0. Workflow `windows.yml` проверяет установщики и отдельные хранилища. На эмуляторе Android проверяется одновременная установка обеих версий, сохранение их карт и восстановление резервной копии.

Локальная релизная сборка Android использует `android/build-test.sh` с переменными `KARTA_KEYSTORE`, `KARTA_PASSFILE` и при необходимости `KARTA_KEY_ALIAS`. Сценарий сверяет сертификат с `android/standalone-cert.sha256`. Workflow `release.yml` принимает тот же ключ через секреты `KARTA_KEY_BASE64` и `KARTA_KEY_PASSWORD` в окружении `android-standalone`. Закрытый ключ и пароль хранятся вне Git.
