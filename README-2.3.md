# Карта связей 2.3

В настройках полотна выберите отдельные радиусы. Введите подписи для нужных колец и настройте размер и цвет текста. В разделе «Сохранённые виды» запишите текущую карту под своим названием. Открытие вида восстанавливает фильтры, положение узлов, масштаб и подписи. Данные карточек остаются общими.

На Android откройте «⋯» и выберите «Добавить из контактов» либо «Добавить и учесть звонки». Вторая команда предлагает подсчитать разговоры за последние 90 дней. Приложение считает входящие и исходящие вызовы с положительной длительностью. Выбор контакта не требует доступа ко всей телефонной книге. Обновление, включая повторный подсчёт в панели группировки, запускает пользователь. Данные об отдельных звонках не сохраняются. Число разговоров, номер и дата расчёта попадают в локальную карту и её резервные копии.

Чем больше разговоров, тем ближе кольцо. Контакты без статистики или с нулём разговоров попадают на внешнее кольцо, если они не закреплены. Настройте как минимум две окружности, чтобы видеть разницу. При отказе Android в доступе к журналу можно импортировать CSV с заголовком `phone,count` и итогами за 90 дней. При совпадении одного номера с несколькими карточками он исключается из расчёта.

Тестовый APK 2.3 устанавливается отдельно от 2.2. Для переноса используйте экспорт и импорт JSON. Подписывается временным тестовым ключом сборки. Пакет Windows содержит прежний запускатель и обновлённый HTML с совместимым именем файла. Готовые сборки находятся в разделе Artifacts успешного запуска GitHub Actions.
